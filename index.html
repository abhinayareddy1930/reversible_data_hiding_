About RDH

Attention-Guided Reversible Data Hiding (T-RDH) combines ViT-based brain segmentation with 3-tier multi-LSB substitution to embed large patient records into brain MRI images with zero diagnostic distortion and pixel-perfect recovery.

Embedding Algorithm

  1. ViT forward pass → brain segmentation mask + CLS-attention map (224×224)
  2. Otsu + morphological closing → full brain ROI mask
  3. Pixels sorted by ascending attention into 3 tiers:
      • Tier 1 (attn < T1 = 0.33): 3 LSBs replaced — most data, safest region
      • Tier 2 (T1–T2): 2 LSBs replaced
      • Tier 3 (attn ≥ T2 = 0.66): 1 LSB replaced — minimal distortion
  4. Original LSBs saved in embed_log → used to restore image perfectly
  5. RCE = 0 guaranteed (pixel-perfect recovery using embed_log)

Why RCE = 0

Each modified pixel's original k LSBs are saved in embed_log. At extract time, those exact original bits are written back — making recovery pixel-perfect regardless of message size or image content.
